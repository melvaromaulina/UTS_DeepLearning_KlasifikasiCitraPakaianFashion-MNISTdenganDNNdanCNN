# Klasifikasi Citra Pakaian Fashion-MNIST (CNN)

Aplikasi demo klasifikasi 10 kelas pakaian dan alas kaki memakai CNN (BatchNorm + Dropout, 436.650 parameter).
Prediksi memakai model TensorFlow Lite, dan penjelasan prediksi memakai Grad-CAM.

Unggah foto satu pakaian atau sepatu (tampak samping, latar polos paling baik).
